# K. Siri Santhoshi — Personal Portfolio

A modern, dark-themed, fully responsive personal portfolio website for **K. Siri Santhoshi**, a B.Tech Data Science student. Built with React, TypeScript, Tailwind CSS, and Vite.

## Project Description

This portfolio showcases the educational background, project experience, and contact information of K. Siri Santhoshi. It features a fixed sidebar navigation on desktop, a mobile hamburger menu, smooth scroll navigation, a timeline-based education section, project cards, and a contact form UI.

## Technologies Used

- **React 18** — UI library
- **TypeScript** — Type-safe JavaScript
- **Tailwind CSS 3** — Utility-first styling
- **Vite 5** — Build tool and dev server
- **Lucide React** — Icon library

## Features

- Dark professional theme with teal accent color
- Responsive sidebar navigation (desktop) with mobile hamburger menu
- Smooth scroll and active section highlighting via Intersection Observer
- Hero section with profile avatar placeholder and action buttons
- About section with quick info cards
- Education timeline with three qualification stages
- Experience and Projects sections with cards
- Contact section with info display and a UI-only contact form
- Subtle fade-in animations on section load
- Custom scrollbar styling
- Accessible contrast ratios and responsive typography

## How to Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) version 18 or higher
- npm (comes with Node.js)

### Steps

1. **Clone the repository**

   ```bash
   git clone https://github.com/<your-username>/personal-portfolio.git
   cd personal-portfolio
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

   The site will be available at `http://localhost:5173`.

4. **Build for production**

   ```bash
   npm run build
   ```

   The built files will be in the `dist/` folder.

5. **Preview the production build**

   ```bash
   npm run preview
   ```

## Git Workflow

The team follows this branching workflow:

```
Clone → Branch → Code → Add → Commit → Pull → Push → Pull Request → Review → Merge
```

### Step-by-step

1. **Clone the repository**

   ```bash
   git clone https://github.com/<your-username>/personal-portfolio.git
   cd personal-portfolio
   ```

2. **Create your branch** (never work directly on `main`)

   ```bash
   # Member 1
   git checkout -b member1-html

   # Member 2
   git checkout -b member2-css

   # Member 3
   git checkout -b member3-js
   ```

3. **Make your changes** — edit the relevant files for your responsibility area.

4. **Stage and commit with a meaningful message**

   ```bash
   git add .
   git commit -m "Add portfolio HTML structure"
   ```

   Example commit messages:
   - "Add portfolio HTML structure"
   - "Create responsive portfolio design"
   - "Add JavaScript navigation"
   - "Add education section"
   - "Add CivicFix project"

5. **Pull the latest changes from main before pushing**

   ```bash
   git fetch origin
   git rebase origin/main
   ```

6. **Push your branch**

   ```bash
   git push origin member1-html
   ```

7. **Open a Pull Request** on GitHub from your branch to `main`.

8. **Review** — another team member reviews the PR.

9. **Merge** — after approval, merge the PR into `main`.

> Never directly modify the `main` branch during collaborative development.

## Deployment

### Option 1: GitHub Pages

1. Build the project:

   ```bash
   npm run build
   ```

2. The `dist/` folder contains the built site.

3. If your repository is named `personal-portfolio`, set the `base` in `vite.config.ts`:

   ```ts
   export default defineConfig({
     base: '/personal-portfolio/',
     // ... rest of config
   });
   ```

4. Install the GitHub Pages deploy tool:

   ```bash
   npm install --save-dev gh-pages
   ```

5. Add deploy scripts to `package.json`:

   ```json
   "scripts": {
     "deploy": "npm run build && gh-pages -d dist"
   }
   ```

6. Deploy:

   ```bash
   npm run deploy
   ```

7. In your GitHub repo, go to **Settings → Pages** and set the source to the `gh-pages` branch.

### Option 2: Vercel

1. Push your code to GitHub.

2. Go to [vercel.com](https://vercel.com) and sign in with GitHub.

3. Click **Add New → Project** and import your repository.

4. Vercel auto-detects Vite. The settings should be:
   - **Framework preset:** Vite
   - **Build command:** `npm run build`
   - **Output directory:** `dist`

5. Click **Deploy**. Your site will be live at a `vercel.app` URL.

6. (Optional) Add a custom domain in **Settings → Domains**.
